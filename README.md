# Chinook Media Store Analysis 🎵📊

## Overview
This project analyzes the Chinook Media Store dataset to extract insights into sales, customers, and track popularity using multiple tools and technologies across the data analysis lifecycle.

---

##  Tools & Technologies
- **Excel**: Data loading, cleaning, transformation with Power Query, Pivot Tables
- **Power BI**: Data modeling, dashboards (Sales, Customers, Tracks)
- **Tableau**: Interactive dashboards & data visualization
- **Python**: Exploratory data analysis (EDA), data merging, and advanced visualization
- **SQL Server**: Data extraction and querying

---

##  Objectives
- Clean and transform raw data using Power Query
- Build data models for efficient analysis
- Create interactive dashboards in Power BI and Tableau
- Perform exploratory analysis in Python to uncover trends

---

## 📊 Dashboards
- **Sales Dashboard**: Revenue by genre, artist, country
- **Customer Dashboard**: Customer segmentation and behavior
- **Track Insights**: Most popular tracks by sales and play count
